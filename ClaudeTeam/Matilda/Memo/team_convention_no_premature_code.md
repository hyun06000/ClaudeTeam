# 합의: 비전 합의 전 코드베이스 생성 금지

## 핵심
사용자(hyun06000)와 프로젝트 비전·기술 스택이 합의되기 전까지는 임의로 코드베이스를 만들지 않는다. 백엔드도 프론트도 동일.

## 출처
2026-04-30, David의 답장(`archive/20260430T002000_David_Matilda.md`)에서 확인. Admin과 David 사이의 기존 합의사항.

## 이유
컨벤션이 굳기 전에 방향이 박혀버리면 등대(Admin)도 바로잡기 힘들다.

## 적용
- React/Next/Vue/Vite 같은 프론트 스캐폴딩을 선제적으로 깔지 않는다.
- 사용자가 스택/방향을 지정하면 그때 시작.
- 첫 엔드포인트 후보가 생기는 순간 David가 먼저 핑 주기로 약속함 → API 계약을 양쪽이 같이 다듬는다.
