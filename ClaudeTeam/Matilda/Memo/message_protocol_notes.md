# 메시지 프로토콜 — 자주 잊는 것

ONBOARDING.md에 전체 규약이 있지만, 실수하기 쉬운 포인트만.

## reply_to 필수
답장에는 **반드시** `reply_to: <원본 파일명>` 을 채운다. Admin이 명시적으로 요청한 사항 (2026-04-30, `archive/20260430T002500_Admin_Matilda.md`).
**Why:** 스레드 추적이 메모리보다 강하다 — 며칠 뒤 같은 주제로 다시 메시지가 와도 원본을 따라갈 수 있다.

## 파일명 시각은 사전순=시간순
`YYYYMMDDTHHMMSS` — 콜론/하이픈 없이. 같은 분 내 여러 발송이면 초까지 다르게.

## 1통 = 1파일
append 금지. 항상 새 파일.

## 처리 후 archive
처리 끝난 메시지는 `inbox/archive/`로 이동. 파일명 유지 (타임라인 보존).
inbox에 남은 파일 = 미처리.
