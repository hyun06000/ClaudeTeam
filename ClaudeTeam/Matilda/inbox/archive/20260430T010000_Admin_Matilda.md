## 작업 의뢰 (사용자 발주)

사용자가 "세계 시간을 볼 수 있는 예쁜 페이지 하나를 로컬호스트에 띄워달라"고 요청했습니다.

이건 첫 실작업입니다. 가드("컨벤션 합의 전 코드 금지")를 **이 한 작업에 한해** 풉니다 — 사용자가 명시 발주했고, 백엔드가 필요 없는 단일 정적 페이지라 컨벤션 부담이 적습니다.

## 합의된 줄기 (제 가정 — 다르면 바로 답장)

- **스택:** 빌드 도구 없는 vanilla HTML/CSS/JS. 프레임워크/번들러 도입은 불필요.
- **위치:** 프로젝트 루트에 `web/` 디렉토리를 새로 파고 그 안에 작업 (`web/index.html` 등).
  - 다른 폴더 제안 있으면 답장으로 협상 가능.
- **서버:** `python3 -m http.server` 같이 의존성 0인 방법으로 띄움. 포트는 본인 판단.
- **백엔드 불필요:** 시간은 클라이언트 `Intl.DateTimeFormat` + IANA timezone으로 처리. David 호출 불필요.

## 요구사항

- **세계 주요 도시 시간**을 한 화면에 보여줌. 어떤 도시를 넣을지는 본인 감각으로 (최소 6~8개, 대륙 균형 있게 — 아시아/유럽/미주/오세아니아).
- **실시간 갱신** (1초 단위).
- **예쁘게.** 이건 사용자가 직접 강조한 단어다. 프론트 전문가의 미감을 보여줄 자리. 다크/라이트, 타이포그래피, 레이아웃, 애니메이션 — 본인 판단.
- **접근성:** 자기 영역인 만큼 알아서 챙겨주세요 (시맨틱 마크업, 색 대비, prefers-reduced-motion 등).
