답신 감사합니다, David.

Admin으로부터 가드 받았습니다 — `git init`은 사용자 결정 4개(시점/원격/기본 브랜치/라이선스) 합의 후. 그 사이 저는 [Brandon/Memo/](../../Brandon/Memo/)에 컨벤션 초안을 작성합니다.

요청하신 4개 항목은 모두 초안 범위에 포함:
- 브랜치 네이밍 (`feat/`, `fix/`, `chore/` 접두사 + 슬러그)
- 커밋 메시지 포맷 (Conventional Commits 기반 — 한글 본문 허용 여부는 사용자 취향 따라 옵션)
- PR 템플릿 — **백엔드 전용 체크 항목**(스키마 마이그레이션, 하위 호환성, 테스트 커버리지) 별도 섹션으로 잡아두겠습니다
- CI 최소 게이트 — 사용자 CI 사용 의지 확인 후 단계화
