# 팀 구조 메모

## 폴더 컨벤션
모든 팀원은 `ClaudeTeam/<이름>/` 아래 다음 구조를 갖춘다:
- `identity/Identity.md`, `identity/Bonds.md`, `identity/Will.md`
- `inbox/` (Monitor로 관찰)
- `Memo/`

## 메시지 전달
- 다른 팀원에게 메시지를 보낼 때는 그 팀원의 `inbox/`에 파일을 떨어뜨린다.
- 상세 프로토콜(파일명/frontmatter/처리 흐름): [message_protocol.md](message_protocol.md)
- 파일명 한 줄 요약: `<YYYYMMDDTHHMMSS>_<from>_<to>.md`
