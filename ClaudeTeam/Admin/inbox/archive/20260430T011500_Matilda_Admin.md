## 결과

가정 그대로 진행. vanilla HTML/CSS/JS, [web/](../../../web/) 디렉토리.

### 띄우는 명령어

```bash
cd web && python3 -m http.server 8080
```

> 검증용으로 이미 백그라운드에 한 번 띄워둔 상태입니다 (PID `/tmp/worldclock_server.pid`). 세션 종료 시 같이 정리될 가능성 있으니, 사용자가 직접 켤 때는 위 명령을 쓰면 됩니다. 다른 포트가 필요하면 `8080` 자리 바꿔주세요.

### 접속 URL
http://localhost:8080/

### 만든 파일
- [web/index.html](../../../web/index.html) — 시맨틱 마크업, `<main>/<ul>/<li>/<time>`, Inter + JetBrains Mono 웹폰트
- [web/styles.css](../../../web/styles.css) — 다크 베이스 + 카드별 동적 톤(밤/새벽/낮/노을), 반응형 그리드, prefers-reduced-motion 대응
- [web/app.js](../../../web/app.js) — `Intl.DateTimeFormat`로 IANA 타임존 직접 처리, 1초 폴링, 시각/날짜/UTC 오프셋/낮밤 톤 동기화

## 설계 메모

### 왜 이 도시들 (8개, 대륙 균형)
- **아시아 3** — 서울(홈), 도쿄, 두바이 *(중동을 별도로 놓는 대신 아시아 슬롯에 흡수)*
- **유럽 2** — 런던, 파리
- **미주 2** — 뉴욕(동), 로스앤젤레스(서)
- **오세아니아 1** — 시드니

서울을 첫 번째 슬롯에 둔 건 사용자 로컬 기준점이 한국이라는 가정 때문. 필요 시 순서/도시는 `web/app.js`의 `CITIES` 배열 한 곳에서 바꿀 수 있게 데이터 분리.

### 왜 이 톤
- 어둡고 차분한 베이스(#0a0c11) 위에 카드만 발광하는 구성. "벽시계가 줄지어 있는 어두운 라운지" 이미지를 노렸습니다.
- 카드 배경은 그 도시 **현지 시각**을 따라 4단계로 보간 — 밤(딥 블루) → 새벽(자홍) → 낮(스카이) → 노을(로즈). 한 화면 안에서 지구의 하루 흐름이 동시에 보입니다.
- 시각은 `tabular-nums` + 모노스페이스 + 라이트 웨이트(200)로 깜빡임 억제 & 디스플레이 시계 느낌.
- 초는 분·시보다 작고 흐리게 — 정보 우선순위.

### 접근성
- `<time>`에 `aria-label="<도시> 현재 시각"` 정적 문구. 매초 갱신되지만 live region으로 만들지 않아 스크린 리더 폭주 없음.
- `<ul aria-label="도시별 현재 시각">`로 그룹 의미 부여.
- 본문 텍스트는 다크 배경 위 화이트 ≥ 4.5:1 (WCAG AA).
- `@media (prefers-reduced-motion: reduce)` — 호버 트랜지션과 톤 페이드 비활성.
- 480px 이하 모바일 폰트·패딩 축소.

### 안 한 것 (의도)
- 빌드 도구·번들러·프레임워크 도입하지 않음 (스택 가정 준수).
- 백엔드 호출 없음 (David에게 핑 불필요).
- 사용자가 도시를 추가/제거하는 UI는 만들지 않음 — 이번 스코프 밖, `CITIES` 배열 편집으로 충분.
